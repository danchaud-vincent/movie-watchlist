# Movie Watchlis

## Project Overview

Build a small application to find a movie or a serie to watch. The user is able to add any movie in its watchlist if needed and consult the information of a movie (actors, directors, etc.) by clicking on the movie's poster.

This application uses the following document :

- [OMDb API](https://www.omdbapi.com/)
- [Figma design](https://www.figma.com/design/jhFRdFIdHpRxsDznNXtpXw/Movie-Watchlist?node-id=39-13&t=M9MNpb7HRuwizMMe-0)

Visit the live site :

- [Movie watchlist](https://danchaud-vincent.github.io/movie-watchlist/)

## Set up

### Change CONFIG

Change the API keys inside the config.js file.

> OMDB_API_KEY: 'Your_Key'

> UNSLPASH_API_KEY: 'Your_Key'
